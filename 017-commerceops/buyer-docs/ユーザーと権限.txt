────────────────────────────────────────
CommerceOps　ユーザーと権限
────────────────────────────────────────

対象の版：CommerceOps 1.0.0（2026年9月）

この文書では、組織のメンバー（ユーザー）のロール（役割）ごとに、
使える画面・できる操作・見える個人情報を説明し、招待・パスワード再設定・
無効化などの管理方法をまとめます。
メンバーの管理は、Owner が「設定」→「ユーザー・権限」で行います。
文中の「」は、主に画面に表示されるメニュー・画面・ボタン・メッセージを示します。
例に出てくる氏名・メールアドレスはすべて架空のものです。


■ 1. 5 つのロール

1 人のユーザーは、組織ごとに次のどれか 1 つのロールを持ちます。
画面の表示を切り替えるだけでなく、サーバー側でも毎回権限を確認して
いるため、権限のない操作は画面を経由しなくても実行できません。

・Owner（オーナー）
  組織の管理者です。すべての操作に加えて、「設定」（組織・運用設定、
  倉庫・ロケーション、ユーザー・権限、販売チャネル、Import Profile、
  バックアップ・復元）を使えます。
・Operations Manager（運用管理）
  日々の業務全体の責任者です。取込・引当・Wave・出荷確定・返品の検品・
  例外対応・作業割当・KPI・監査ログ・CSV 出力ができます。
  「設定」は使えません。
・Picker（ピッキング）
  スマホで Pick タスクを担当し、棚から商品を集めます。
  お客様の氏名・住所・電話番号・メールアドレスは表示されません。
・Packer（梱包）
  Packing Station で検品・梱包し、返品の到着を登録します。
  表示される個人情報は、送付先の氏名・郵便番号・住所だけです。
・Customer Support（顧客対応）
  注文の確認、住所変更・保留、返品の受付・承認、交換の手配をします。
  在庫の調整、出荷確定、返品の到着登録・検品、CSV 出力はできません。

この文書では、Owner と Operations Manager をまとめて「管理者」と書きます
（画面上の「強制完了（管理者）」などの「管理者」も同じ意味です）。

【ログインした直後に開く画面】
・Picker …………… スマホ作業モード
・Packer …………… スマホでは「スマホ作業モード」、iPad・PC では
                     「Packing Station」
・それ以外 ………… ホーム

権限のない画面のアドレスを直接開くと「アクセスできません」
「この画面を表示する権限がありません。必要な場合は組織のオーナーに
依頼してください。」と表示されます。


■ 2. メニューの表示（ロール別）

左側（スマホ・iPad の縦向きなどでは、左上のメニューボタンで開く）の
メニューには、そのロールで使えるものだけが表示されます。

・Owner
    すべてのメニュー
・Operations Manager
    「設定」以外のすべて（ホーム、注文、注文取込、引当、Fulfillment、
    Wave・ピッキング、Packing Station、出荷、返品・交換、例外キュー、
    作業割当、在庫・商品、KPI、スマホ作業モード、監査ログ）
・Picker
    ホーム、Wave・ピッキング、スマホ作業モード
・Packer
    ホーム、Packing Station、出荷、返品・交換、スマホ作業モード
・Customer Support
    ホーム、注文、出荷、返品・交換、例外キュー、在庫・商品

画面上部の検索欄は全員が使えます。検索結果には、その人が見てよい情報
だけが表示されます。


■ 3. 画面ごとにできること

【ホーム】
・全員：その人に権限のある項目の件数だけが表示されます。
  倉庫範囲（6 章）が限定されている人は、倉庫に関係する件数（Wave 待ち・
  ピッキング中・梱包・出荷・返品・例外など）がその倉庫の分だけになります
  （注文の件数は組織全体です）。

【注文】
・管理者：一覧・詳細（個人情報を含む）、「手動で注文作成」「CSV 取込」、
  「保留にする」「保留を解除」、「優先度・備考」、「住所変更」（出荷前
  のみ）、「商品を対応付け」「再検証（商品登録後など）」、「キャンセル」
  「明細取消」、注文画面での引当（「ルールで引当」「揃った分を先行出荷」
  「出荷作業を作成」「引当解除」）、「返品・交換受付」、「CSV 出力」、
  「操作履歴（監査ログ）」の表示
  （「出荷作業を作成」は、全量引当の注文を自動で出荷作業にしない設定の
  ときに表示されます）
・Customer Support：一覧・詳細（個人情報を含む）、保留・保留の解除、
  優先度・備考、住所変更（出荷前のみ）、商品の対応付け・再検証、
  返品・交換受付。キャンセル・取込・手動作成・引当・CSV 出力はできません。
・Picker・Packer：使えません。

【注文取込】
・管理者：CSV の取込（プレビュー・確定・取消）と取込履歴の確認
・取込に使う Import Profile の作成・変更は Owner だけができます
  （「設定」→「Import Profile」）。

【引当】【Fulfillment】
・管理者のみ使えます。

【Wave・ピッキング】
・管理者：「Wave を作成」「Wave を取消」、Pick タスクの「割当」
  「担当解除」「まとめて割り当て」、「Pick List 印刷」
・Picker：Wave と Pick タスクの閲覧、「Pick List 印刷」、「ピック画面」
  を開くこと。Wave の作成・取消・担当の割当はできません。

【スマホ作業モード】
・Pick（タスクの開始・読み取り・Short の報告・訂正・中断）
    管理者、Picker
・商品確認
    スマホ作業モードを使える全員。在庫数は管理者だけに表示され、
    Picker・Packer には置き場所（倉庫・ロケーション）だけが表示されます。
・返品
    到着の登録は管理者と Packer。検品（再販可・破損などの判定）は
    管理者だけができます。
・報告（例外を報告）
    全員

【Packing Station】
・Packer：梱包の開始（注文番号・出荷作業番号の読み取り、「梱包開始」、
  自分の梱包の「再開」、作業期限が切れた梱包の「引き継ぐ」）、
  1 個ずつの読み取り検品、「1 個取消」「残りをまとめて入力」
  「箱を閉じて次の箱へ」「梱包完了」、自分の梱包の「中止」、
  「納品書を印刷」、出荷作業票の印刷
・管理者：上記に加えて、「強制完了（管理者）」（全数そろう前に完了
  する操作。理由が必須で、例外キューと監査ログに記録されます）、
  作業中の梱包の「管理者として引き継ぐ」、他の人の梱包の「中止」

【出荷】
・管理者：配送会社・追跡番号の入力と「保存」「出荷確定」、
  「選択した荷物を出荷確定」、
  「scan で出荷確定（ハンディスキャナ / カメラ）」、「追跡番号 CSV 取込」、
  出荷後の追跡番号の訂正（理由が必須）、「出荷予定 CSV」「出荷実績 CSV」
・Packer・Customer Support：一覧・詳細の閲覧と「作業票を印刷」だけです
  （出荷確定はできません）。

【返品・交換】
・管理者：すべての操作（「返品を受け付ける」「承認」「返送中にする」
  「到着を登録」、検品・判定と「検品結果を確定（在庫に反映）」、
  「交換品を手配」「却下」「取消」「受領票を印刷」「CSV 出力」）
・Customer Support：「返品を受け付ける」「承認」「返送中にする」
  「交換品を手配」「却下」「取消」「受領票を印刷」。
  到着の登録と検品はできません。
・Packer：一覧・詳細の閲覧（お客様からの連絡内容などのメモは表示され
  ません）、「到着を登録」、「受領票を印刷」。受付・承認・検品・交換は
  できません。
・Picker：使えません。

【例外キュー】
・管理者：一覧・詳細、担当者の割当、「調査中にする」「解決」「対応不要」
  「再オープン」、コメントの記録、在庫不整合の
  「見つかった（引当可能に戻す）」「紛失確定（在庫を減らす）」、「CSV 出力」
・Customer Support：一覧・詳細の閲覧だけです。
・Picker・Packer：例外キューは開けませんが、スマホ作業モードの「報告」
  から現場の問題を報告できます。

【作業割当】
・管理者のみ使えます。

【在庫・商品】
・管理者：在庫一覧・「在庫履歴」、「入荷を登録」「在庫CSV取込」
  「在庫CSV出力」、在庫の「調整」「移動」「調査中を解消」、
  商品（SKU）の「商品を追加」「CSV 取込」とバーコードの登録
・Customer Support：在庫・在庫履歴・商品の閲覧だけです。
・Picker・Packer：使えません（スマホ作業モードの「商品確認」で、
  商品と置き場所を確認できます）。

【KPI】【監査ログ】
・管理者のみ使えます（それぞれの「CSV 出力」を含みます）。

【設定】
・Owner のみ使えます。「組織・運用設定」「倉庫・ロケーション」
  （ロケーションラベルの「ラベル印刷」を含む）「ユーザー・権限」
  「販売チャネル」「Import Profile」「バックアップ・復元」

【画面上部の検索】
・全員が使えます。結果は、その人が見てよい情報だけです。
  顧客名・郵便番号での注文の検索は、注文と個人情報を見られるロール
  （管理者・Customer Support）だけが使えます。


■ 4. 個人情報の見え方

・管理者・Customer Support
    注文の詳細画面で、購入者の氏名・メールアドレス・電話番号と、
    送付先の氏名・郵便番号・住所・電話番号を表示します。
    注文の一覧では送付先の氏名と都道府県までを表示し、電話番号・
    メールアドレスは詳細画面だけに表示します。
・Packer
    送付先の氏名・郵便番号・住所と注文の備考だけを表示します
    （Packing Station の「送付先」、納品書、出荷の詳細画面・出荷作業票）。
    電話番号・メールアドレス・購入者（注文者）の情報は表示されません。
    注文の画面は開けません。
・Picker
    お客様の氏名・住所・電話番号・メールアドレスは一切表示されません。
    Pick の画面に出るのは、ロケーション、商品（SKU・商品名）、数量、
    出荷作業番号（F-）などです（Wave の画面では注文番号も表示されます）。

そのほかの取り扱い
・監査ログには、氏名・住所・電話番号・メールアドレスを記録しません
  （注文番号・件数・理由の有無などを記録します）。
・サーバーのログにも、個人情報や画面に入力した内容を記録しない設計です。
・現場からの報告のメモや、例外のコメントには、お客様の氏名・住所・
  電話番号などを書かないでください（画面にも注意書きがあります）。
・納品書と出荷作業票には送付先の氏名・住所が印字されます。
  印刷物の保管・廃棄に注意してください。
・Customer Support は、お客様対応のため個人情報をすべて見られます。
  このロールを付ける人は慎重に選んでください。


■ 5. CSV 出力と個人情報

・CSV を出力するボタン（「CSV 出力」「在庫CSV出力」「出荷予定 CSV」
  「出荷実績 CSV」、KPI・監査ログの「CSV 出力」）は、管理者（Owner・
  Operations Manager）にだけ表示されます。ほかのロールは出力できません。
・注文の「CSV 出力」では、個人情報の範囲を選びます。
    「含めない（注文番号・商品・数量のみ）」
    「送付先（氏名・住所）を含める」
    「電話・メール・購入者情報も含める」
  必要な範囲だけを出力してください。
・「出荷予定 CSV」（送り状ソフトなどへの取込用）には、送付先の氏名・
  住所・電話番号が入ります。
・出力できるのは 1 回に最大 10 万行です。文字コードは「UTF-8（BOM 付き）」
  と「Shift_JIS」から選べます。
・出力したことは監査ログに記録されます（件数・範囲・個人情報の範囲を
  記録し、ファイルの中身は記録しません）。
・ダウンロードしたファイルの保存場所・共有・削除は、購入者の責任で
  管理してください。


■ 6. 倉庫範囲（担当する倉庫を限定する）

倉庫範囲は、そのメンバーが扱える倉庫です。初期状態は「全倉庫」です。

【設定のしかた】
 1. 「設定」→「ユーザー・権限」を開きます。
 2. 対象の人の「倉庫範囲」の列のボタン（「全倉庫」または倉庫コードが
    表示されています）を押します。
 3. 扱う倉庫にチェックを付けて「選択した倉庫に限定」を押します。
    元に戻すときは「全倉庫にする」を押します。
招待するときに「倉庫範囲（未選択 = 全倉庫）」で指定することもできます。
変更は、その人の次の操作からすぐに反映されます。

【倉庫範囲で絞られるもの】
・Wave・Pick タスク、梱包、出荷（荷物）、在庫、倉庫が決まった返品、
  倉庫に紐づく例外の閲覧と操作
・ホームの倉庫作業などの件数、KPI、検索結果（荷物・Wave・出荷作業・
  返品など）、在庫・出荷・返品・例外の CSV 出力
・作業割当や例外の担当者の候補（その倉庫を扱える人だけが表示されます）

【倉庫範囲では絞られないもの】
・注文（一覧・詳細・注文の CSV 出力）、注文取込、引当は組織全体が対象です。
・倉庫がまだ決まっていない返品や、倉庫に紐づかない例外（欠品など）は、
  それを閲覧できるロールの全員に表示されます。


■ 7. メンバーを招待する

CommerceOps はメールを送信しません。招待は、Owner が作成した
「招待リンク」を本人に渡す方式です。

【Owner の操作】
 1. 「設定」→「ユーザー・権限」→「メンバーを招待」を押します。
 2. 「メールアドレス（ログインID）」「氏名（任意）」「ロール」
    「倉庫範囲（未選択 = 全倉庫）」を入力・選択します。
    例：yamada@example.com、山田 太郎、Picker（ピッキング）
 3. 「招待リンクを作成」を押すと、「招待リンク（7日間有効・1回限り）」
    が表示されます。
    「このリンクは今だけ表示されます。本人に安全な方法で渡してください
    （メールは自動送信されません）。」とあるとおり、リンクはこの画面で
    しか表示されません。「コピー」を押してコピーし、本人だけに渡します。
 4. 画面下の「招待」の一覧で状態（未承諾・参加済・取消・期限切れ）を
    確認できます。未承諾の招待は「取消」できます。

リンクをなくした・期限が切れた場合は、招待を「取消」して、もう一度
「メンバーを招待」から作り直してください（同じリンクを再表示する機能は
ありません）。すでにこの組織の有効なメンバーであるメールアドレスには
「このメールアドレスのユーザーは既にメンバーです」と表示されます。

【招待された人の操作】
 1. 受け取ったリンクを開くと「招待を受け入れる」画面が表示されます
    （「◯◯ に ◯◯ として招待されています。」と組織名・ロールが出ます）。
 2. 初めて CommerceOps を使う人：「お名前」と
    「パスワードを設定（10文字以上）」を入力して「参加する」を押します。
    すでに CommerceOps のアカウントを持っている人（他の組織で使っている
    人など）：「既存アカウントのパスワード」を入力して「参加する」を
    押します。
 3. 参加するとログインした状態になり、ロールに応じた画面が開きます。
    次回からは、メールアドレスとパスワードでログインします。

【招待で表示される主なメッセージ】
・「招待リンクが無効か期限切れです」……期限切れ・取消済み・使用済みの
  リンク、またはリンクの一部が欠けている場合
・「既存アカウントのパスワードが正しくありません」
・「このアカウントは無効化されています」……アカウント自体が停止されて
  います。サーバー運用者に相談してください。
・「このメールアドレスのアカウントは他の組織にも所属しています。…」
  ……11 章を参照してください。

【注意】
・招待リンク・再設定リンクは本人だけに渡し、複数人が見るチャットなどに
  残さないでください。
・リンクのアドレスは、サーバーの設定（APP_BASE_URL）をもとに作られます。
  リンクのアドレスが正しくない場合は、サーバー運用者に確認してください。


■ 8. パスワードの変更と、忘れたときの再設定

【自分でパスワードを変更する】
ログインしている人は、自分でパスワードを変更できます。
 1. 画面右上（ユーザー名の横）の「パスワード変更」ボタンを押します。
    ・狭い画面（スマホなど）では、左上のメニューボタン（三本線）で開く
      メニューの下部（「ログアウト」の隣）にあります。
    ・スマホ作業モードでは、「ホーム」の画面（「ログアウト」の近く）に
      あります。
 2. 「現在のパスワード」「新しいパスワード」（10 文字以上。推測されやすい
    ものは使えません）「新しいパスワード（確認）」を入力し、「変更する」を
    押します。
 3. 「パスワードを変更しました（他の端末のログインは終了しました）」と
    表示されます。この端末はそのまま使えます。ほかの端末でログインして
    いた場合、そちらはログアウトされるので、新しいパスワードでログインし
    直します。
・「現在のパスワードが正しくありません」と表示されたら、今のパスワードを
  確認してください。確認欄に「新しいパスワードと一致しません」と表示され
  たら、確認欄を入れ直してください。
・サーバー運用者がコマンドで作成した最初の Owner や、サンプル組織の
  サンプル用アカウントのパスワード（作成したときに 1 回だけ表示されます）
  は、ログインしたらすぐに変更してください。

【パスワードを忘れたとき（Owner が再設定リンクを発行）】
ログイン画面にも「パスワードを忘れた場合は、組織のオーナーにリセット
リンクの発行を依頼してください。」と表示されています。

【Owner の操作】
 1. 「設定」→「ユーザー・権限」で、対象の人の行の「PWリセット」を
    押します。
 2. 「◯◯ さんのパスワード再設定リンク（24時間有効）」が表示されるので、
    「コピー」して本人だけに渡します（メールは送信されません）。

【本人の操作】
 1. リンクを開くと「パスワードの再設定」画面が表示されます。
 2. 「新しいパスワード（10文字以上）」を入力して「変更する」を押します。
 3. 「パスワードを変更しました。新しいパスワードでログインしてください。」
    と表示されたら「ログイン画面へ」を押してログインします。

【知っておくこと】
・再設定リンクは 24 時間有効で、1 回だけ使えます。新しいリンクを発行
  すると、それまでの未使用のリンクは使えなくなります。
・再設定リンクでパスワードを設定すると、その人はすべての端末でログアウト
  されます。ログインの一時ロック（下記）も解除されます。
・パスワードは 10 文字以上です。同じ文字だけのものや、「password123」
  「1234567890」「qwertyuiop」「commerceops」などを含むものは使えません
  （自分で変更するときも、再設定リンクで設定するときも同じです）。
・Owner が 1 人だけで、その Owner がパスワードを忘れた場合は、組織内で
  リンクを発行できる人がいません。サーバー運用者に依頼してください
  （11 章のコマンド）。

【ログインの制限】
・同じアカウントで 5 回続けて失敗すると、15 分間ログインできなくなります
  （ログイン画面の注意書き「5回続けて失敗すると15分間ログインできなく
  なります。」）。時間がたつと自動で解除されます。
・同じネットワーク（同じ IP アドレス）からのログインは、初期設定で
  15 分間に 20 回までです。多くの人が同じ事務所・倉庫の回線から一斉に
  ログインする場合、「リクエストが多すぎます。◯秒後に再試行して
  ください」と表示されることがあります。その場合はサーバー運用者に
  設定（LOGIN_RATE_LIMIT_MAX）の見直しを相談してください。
・ログイン状態は、操作しないまま 12 時間たつか、ログインから 7 日たつと
  切れます（初期設定。サーバー運用者が変更できます）。


■ 9. ロールの変更・無効化

【ロールを変更する】
・「設定」→「ユーザー・権限」の「ロール」の欄で選ぶと、すぐに保存され
  ます（「更新しました」と表示）。確認の画面は出ません。
・ロールを変更すると、その人がこの組織でログインしている画面はすべて
  ログアウトされます（新しい権限をすぐに反映するため）。本人は、
  もう一度ログインすると新しいロールで使えます。
・作業中の人のロールを変えるときは、作業の区切りで行ってください。
・倉庫範囲の変更ではログアウトされず、次の操作から反映されます。

【無効化する（退職・異動など）】
・対象の人の行の「無効化」を押すと、すぐに無効になります（確認の画面は
  出ません。間違えたときは「有効化」で戻せます）。
・無効にした人は、この組織を使えなくなり、この組織でログインしている
  画面もすぐにログアウトされます。ほかの組織に所属していない場合、
  ログインしても「所属組織がありません」と表示されます。
・その人が行った操作の記録（監査ログなど）はそのまま残ります。
・ユーザーを削除する機能はありません。使わなくなった人は無効化して
  ください。
・無効にした人が担当していた Pick タスクは、「作業割当」で「付け替え」
  「解除」ができます。梱包は、「作業割当」で「中止」するか、Packing
  Station で「管理者として引き継ぐ」ことができます。どちらも、担当の期限
  が切れると、他の人が引き継げる状態になります。


■ 10. 最後の Owner の保護

・組織の Owner が 1 人だけのとき、その人を別のロールに変更したり、
  無効化したりすることはできません。「最後の Owner を降格・無効化する
  ことはできません」と表示されます（組織を管理できる人がいなくなるのを
  防ぐため）。
・Owner が 1 人だけだと、その人が不在の間は、ユーザーの招待・設定の変更・
  バックアップができません。信頼できる人をもう 1 人 Owner にしておくことも
  検討してください。


■ 11. アカウント乗っ取り対策と、リンクを発行できないときの対処

CommerceOps はメールを送らず、Owner がリンクを本人に渡す方式のため、
リンクを作成した Owner 自身もそのリンクを開けてしまいます。
そこで、他の組織にも所属しているアカウントのパスワードを、一方の組織の
Owner が設定できないようにしています。このため、次の 2 つの場面で
操作が止まることがあります。

【場面 1：招待を承諾しようとしたら止まった】
表示：「このメールアドレスのアカウントは他の組織にも所属しています。
所属先から発行されたパスワード再設定リンクでパスワードを設定してから、
招待を承諾してください」

・起きる条件：招待されたメールアドレスのアカウントがパスワード未設定で
  （例：サーバー運用者がコマンドでバックアップを復元したときに作られた
  「招待中」のアカウント）、しかも他の組織に所属している場合です。
・対処：
 1. 本人が所属している組織の Owner に、パスワード再設定リンクを発行して
    もらいます。発行できない場合は、下の【場面 2】の方法でサーバー運用者
    に発行してもらいます。
 2. リンクからパスワードを設定します。
 3. もう一度招待リンクを開き、「既存アカウントのパスワード」を入力して
    「参加する」を押します（招待の期限が切れていたら、招待を作り直して
    もらいます）。

【場面 2：Owner が「PWリセット」を押したら止まった】
表示：「このユーザーは他の組織にも所属しているため、パスワード再設定
リンクを発行できません。本人に現在のパスワードでログインしてもらうか、
サービス運用者に依頼してください」

・起きる条件：対象の人が、あなたが Owner ではない別の組織にも所属して
  いる場合です（その組織で無効化されている所属も含みます）。
・対処：本人が現在のパスワードを覚えていれば、そのまま使うか、本人が
  「パスワード変更」（8 章）で変更します。
  忘れている場合は、サーバー運用者（メッセージの「サービス運用者」。
  CommerceOps のサーバーを管理する担当者）が、本人確認をしてから
  サーバー上で次のコマンドを実行し、再設定リンクを発行します。

    npm run password-reset -w server -- --email yamada@example.com

  ビルド済みの本番環境（server フォルダ内）では次のとおりです。

    node dist/scripts/password-reset-cli.js --email yamada@example.com

  Docker Compose で動かしている場合は次のとおりです（2 行で 1 つの
  コマンドです）。

    docker compose exec app \
      node dist/scripts/password-reset-cli.js --email yamada@example.com

  表示されたリンクは 24 時間有効・1 回限りです。本人だけに安全な方法で
  渡してください（発行したことはサーバーのセキュリティ記録に残ります）。
  手順の詳細はサーバー運用者向けの docs/OPERATIONS.md にあります。


■ 12. 複数の組織に所属している場合（組織の切り替え）

・1 つのアカウント（メールアドレス）で、複数の組織に所属できます
  （例：自社の組織とサンプル組織、バックアップから復元した組織）。
  ロールと倉庫範囲は組織ごとに別々です。パスワードは全組織で共通です。
・2 つ以上の組織に所属していると、画面右上に組織名の選択欄が表示されます。
  スマホなど幅の狭い画面では、左上のメニューボタン（三本線）で開く
  メニューの下部に表示されます。組織を選ぶと、その組織の「ホーム」に
  移動します。サンプル組織には「（サンプル）」と表示されます。
・ログインした直後は、最後に使っていた組織が開きます。
・スマホ作業モードの画面には、組織の切り替え欄がありません。
  ホーム画面のアイコン（またはブラウザで CommerceOps のトップページ）から
  通常の「ホーム」画面を開いて切り替えてから、スマホ作業モードに戻って
  ください。
・サンプル組織を開いているときは、画面上部に「サンプル組織（Sample
  Commerce）です。本番データとは分離されています。」と表示されます。
  本番の作業をしないよう注意してください。
・別の組織から招待されたときは、「既存アカウントのパスワード」を入力して
  参加します（7 章）。


■ 13. 運用のおすすめ

・1 人に 1 つのアカウントを使い、共有しないでください。監査ログで、誰が
  操作したかが分かるようにするためです。
・倉庫の共有 iPad・スマホは、作業が終わったら必ず「ログアウト」して
  ください。端末には画面ロックを設定してください。
・ロールは、仕事に必要な最小限のものにしてください（Picker・Packer には
  お客様の個人情報がほとんど、または一切表示されません）。
・退職・異動のときは、すぐに「無効化」してください。
・端末をなくしたときは、本人が別の端末で「パスワード変更」をするか
  （ほかの端末はログアウトされます）、Owner が再設定リンクを発行して
  ください（すべての端末でログアウトされます）。必要に応じて無効化して
  ください。
・招待リンク・再設定リンクは本人だけに渡し、使い終わったら記録を残さない
  ようにしてください。
