# 料金調査メモ（調査日: 2026-09-30）

OPERATING_COSTS.md の根拠資料。**契約前に必ず各社公式ページで再確認すること。**

## 取得方法と信頼度
- 公式料金ページへの直接アクセス（WebFetch）は実行環境のプロキシで `EGRESS_BLOCKED` となり取得できなかった
  （render.com, fly.io, railway.com, supabase.com, neon.com, developers.cloudflare.com, aws.amazon.com, resend.com, sendgrid.com, sakura.ad.jp, betterstack.com, grafana.com）。
- **[A]** 公式データを直接取得: AWS Price List API JSON（Lightsail/S3/DataTransfer/SES の ap-northeast-1）、
  Cloudflare 公式ドキュメント検索ツール、Supabase 公式ドキュメント検索ツールで本文取得。
- **[B]** 公式ドメイン限定の Web 検索抜粋（本文未取得。要再確認）。
- **未確認**: いずれでも確認できなかった項目。
- 単位: 断りがなければ USD 税抜。

## Render [B]
- Workspace: Hobby $0 / Pro $25/月 / Scale $499/月（2026-04-23 改定）。帯域 Hobby 5GB / Pro 25GB、超過 $0.15/GB。
- Compute: Starter $7/月（512MB, 0.5CPU）、Standard(1c-2g) $25/月（1CPU, 2GB）。
- Free web service は 15 分無通信でスリープ（本番非推奨）。Background worker は Starter から。Cron は最低 $1/月。
- Postgres: Free 256MB は 30 日で失効・バックアップなし。有料はストレージ $0.30/GB/月、basic-256mb は約 $6（推定）。
  有料 DB は PITR（Hobby 3 日 / Pro 以上 7 日）。
- リージョン: Oregon, Ohio, Virginia, Frankfurt, Singapore（**東京なし**）。

## Fly.io [B]
- shared-cpu-1x: 256MB $1.94 / 512MB $3.19 / 1GB $5.70（月、リージョン別価格。東京 nrt は未確認）。Volume $0.15/GB/月。
- Managed Postgres: Basic $38（1GB）/ Starter $72（2GB）…、ストレージ $0.28/GB、HA・バックアップ（10 日保持）込み、**東京 nrt あり**。
- Egress: 北米・欧州 $0.02/GB、その他 $0.04/GB。恒久無料枠なし。

## Railway [B]
- Hobby $5/月（利用込み）/ Pro $20/月。RAM $10/GB/月、CPU $20/vCPU/月、Egress $0.05/GB、Volume $0.15/GB/月。
- 商用アプリは Pro 推奨。デプロイ先に東京なし（Singapore が最寄り）。

## Supabase [A]（pricing ページ自体は [B]）
- Pro $25/月（$10 Compute Credits 込み）。Compute: Micro 約 $10（1GB）/ Small 約 $15（2GB）/ Medium 約 $60（4GB）。
- DB 8GB 込み、超過 $0.125/GB/月。Egress 250GB 込み、超過 $0.09/GB。Storage 100GB 込み、超過 $0.021/GB。
- 日次バックアップ保持: Pro 7 日。PITR アドオン 7 日 約 $100/月（Small 以上）。Free はバックアップなし・7 日で一時停止。
- **Tokyo (ap-northeast-1) 選択可** [B]。USD 請求・カード払い。

## Neon [B]
- 有料は完全従量（最低額なし）。Launch $0.106/CU-h、Storage $0.35/GB-月。APAC は Singapore/Sydney のみ（**東京なし**）。

## AWS 東京 ap-northeast-1 [A]（Price List API、2026-09 公開版）
- Lightsail（Linux, IPv4 付き）: 1GB ≈ $7 / 2GB ≈ $12 / 4GB ≈ $24（込み転送 2/3/4TB、超過 $0.14/GB）。
- Lightsail マネージド DB（PostgreSQL）: 1GB ≈ $15（Standard）/ ≈ $30（HA）、2GB ≈ $30 / $60。自動バックアップ・7 日 PITR [B]。
- S3 Standard: $0.025/GB-月（最初の 50TB）。PUT 等 $0.0047/1,000、GET $0.00037/1,000。インターネット送信 $0.114/GB（最初の 10TB）。
- SES（東京）: 従来従量 $0.10/1,000 通。2026-07-21 以降の新規は料金プラン制（Essentials $0.16/1,000 通 等）[A/B]。

## Cloudflare R2 [A]（developers.cloudflare.com/r2/pricing, 2026-08-07 更新）
- Standard: $0.015/GB-月、Class A $4.50/100 万、Class B $0.36/100 万、Egress 無料。無料枠 10GB-月・A 100 万・B 1,000 万/月。
- 日本国内保存を保証する手段はなし（apac ヒントはベストエフォート）。
